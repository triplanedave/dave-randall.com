Today's focus: building visibility into Intune API outcomes and admin actions with **Azure Monitor**.

## Turn it on

In Intune's diagnostic settings, send logs to a **Log Analytics workspace**. Routing Intune logs into Azure Monitor unlocks powerful observability across device management operations.

## Then query it

Once the data is flowing, **Kusto Query Language (KQL)** becomes your best friend, enabling deep dives into:

- API success and failure rates
- Policy deployment trends
- Admin activity
